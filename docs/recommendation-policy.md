# 좌석 추천 정책

좌석 추천은 LLM이 결정하지 않고 백엔드의 규칙 기반 엔진이 수행합니다.

## 우선순위

```text
접근성 요구 > 일행 배치 > 명시적 좌석 선호 > 일반 편의
```

## 초기 점수 예시

| 조건 | 좌석 속성 | 점수 |
|---|---|---:|
| 다리 불편 | 앞쪽 | +5 |
| 다리 불편 | 통로 | +3 |
| 창가 선호 | 창가 | +3 |
| 멀미 | 앞쪽 | +4 |
| 2명 이상 | 연속 좌석 | +5 |

최종 점수와 함께 사용자에게 보여줄 `reasons` 목록을 반환합니다. 실제 점수는 접근성 테스트와 사용자 검증 이후 조정합니다.
