# 데모 시나리오

## 정상 경로

사용자 발화:

> 내일 오전 서울에서 대전 가는데 다리가 불편하고 창가가 좋아요.

기대 흐름:

1. 출발지, 도착지, 날짜, 시간대, 접근성 요구, 좌석 선호 추출
2. 서울과 대전을 TAGO 터미널 코드로 매핑
3. 실제 운행편 조회
4. 사용자가 버스 선택
5. 앞쪽 창가 Mock 좌석 추천과 이유 표시
6. 날짜·시간·버스·좌석·금액 최종 확인
7. Mock 예매 생성
8. 화면과 음성으로 완료 안내

## 예외 경로

### 출발지 누락

```text
사용자: 내일 서울 가는 버스 찾아줘.
시스템: 어디에서 출발하시나요?
```

### 검색 결과 없음

인접 시간대를 안내하고 사용자가 다시 선택하도록 합니다.

### 외부 API 장애

TAGO 또는 watsonx 호출에 실패하면 실패 사실을 숨기지 않고 재시도와 데모용 Mock 전환 수단을 제공합니다.
